# Agent Instructions

These instructions apply to the entire repository.

Before making changes:

1. Read `PROJECT_GUIDE.md`.
2. Understand Current Project State.
3. Check unresolved P1/P2 issues.
4. Preserve raw scientific data.
5. Never invent scientific values.
6. Never silently change TRIP/TWIP labels.
7. Never treat repeated observations as independent samples without justification.
8. Maintain experimental/computational provenance.
9. Follow existing dataset/version conventions.
10. After completing the task, update `PROJECT_GUIDE.md`.

Follow the Codex Maintenance Rule in `PROJECT_GUIDE.md`: validate meaningful work, append a Work Log entry, update Current Project State and applicable issue/decision records, and include the guide in the task commit. Do not rewrite or erase historical Work Log or Decision Log entries.

**A coding task is not complete until `PROJECT_GUIDE.md` has been updated.**
