# HEA corrosion ML projects

- **Project name:** HEA corrosion ML projects
- **GitHub URL:** https://github.com/search?q=HEA+corrosion+machine+learning&type=repositories
- **Category:** ML_materials
- **Main purpose:** Repository-discovery reference for machine-learning studies of HEA corrosion.
- **Possible relevance for FeMnCoCrN HEA TRIP/TWIP machine learning project:** Useful mainly for HEA featurization and validation patterns; corrosion targets are not substitutes for TRIP/TWIP mechanisms.
- **Priority:** Low

## Scientific role

**Not relevant.** Corrosion ML addresses a different physical target. It may provide generic examples of composition featurization, missing-data handling, interpretability, or uncertainty, but it should not provide scientific predictors, labels, or validation evidence for this project.

## Possible ML usage

**Feature engineering (method patterns only); data interpretation.** Any resulting quantity must carry the repository version, calculation method, inputs, units, temperature, alloy scope, and computational/experimental domain.

## Relevance to FeMnCoCrN HEA TRIP/TWIP project

At most, reusable software patterns could be adapted to assess descriptors in a FeMnCoCrN-specific model. Corrosion behavior does not supply the physical bridge from **SFE to FCC/HCP phase stability to TRIP/TWIP**, so any connection is methodological rather than scientific.

## Limitations

Electrochemical environments, surface states, corrosion targets, and datasets are not transferable to deformation-induced transformation or twinning. Corrosion labels and model performance cannot validate SFE, phase stability, TRIP, or TWIP; an unresolved search result also supplies no auditable implementation.
