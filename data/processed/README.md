# Processed pilot data

This directory is reserved for validated, versioned outputs derived from raw
sources. The pilot infrastructure adds no extracted records, datasets, labels,
or scientific values.

Every future artifact must:

- identify its input paper and condition records;
- retain original reported values alongside any harmonized representation;
- distinguish experimental measurements from calculated descriptors;
- carry field-level source or calculation provenance;
- preserve parent-study, condition, replicate, and repeated-stage relationships;
- document validation status, schema version, creation method, and correction
  history; and
- use a new version rather than overwrite an earlier artifact.

Existing recovery datasets in this directory predate this pilot intake
infrastructure. They remain preserved under the version history documented in
`PROJECT_GUIDE.md` and must not be interpreted as newly collected pilot data.
